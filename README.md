# 方阵和 Kakurasu

一个基于 Web 的方阵和（Kakurasu）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5191/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 第 1 列/行权重为 1，第 2 列为 2，依此类推
- 每行右侧数字等于该行黑格的列权重和
- 每列下方数字等于该列黑格的行权重和

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 空格/标点 → 黑格；黑格 → 空格 |
| 右键点格 | 空格/黑格 → 标点；标点 → 空格 |
| 左键拖动 | 沿路径连续涂黑或取消（只改与起始格同类型的格子） |
| 右键拖动 | 沿路径连续标点或取消（只改与起始格同类型的格子） |
| Shift/中键拖动 | 平移画布 |
| 滚轮 | 缩放 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 导入题目

工具栏的「文本导入」和「图片导入」都能把外部题目加进题库（上限 20×20）。导入前会先校验：能用规则引擎推出唯一解的直接入库；规则推不满时，小盘面会再回溯确认有解，大盘面只校验数值合法性并提示，确认后再入库。

### 文本导入

输入模板的题面编码 —— 与 `src/game/puzzles-data.ts` 里 `board` 字段完全相同的格式：`行目标|列目标`。

```
39,70,62,71,53,51,69,40,74,68,47,38|52,76,39,34,59,75,49,73,63,65,48,39
```

也接受这些写法：

- 直接粘贴题库条目 JSON（读取其中的 `board` 字段）
- 省略 `|`，改填宽高，按「前 N 个是行、其余是列」切分
- 逗号换成空格或换行，`#` 开头的行视为注释

### 图片导入

选一张方阵和题面截图，程序会：

1. 用深色像素的投影找出贯穿全图的网格线，得到宽高与格子尺寸
2. 取蓝色像素的连通块作为数字字形，按位置分成「右侧行目标」与「底部列目标」
3. 用多种系统字体渲染 0-9 作模板做最近邻匹配，再按「读数是否落在合法区间」挑选最可信的一组

识别结果会以表格列出，可逐格手动修正后再入库。识别依赖数字是**彩色（蓝色）**、且截图包含完整网格；黑白截图请用文本导入。

命令行同样可以识别并写入题库（与面板共用 `src/game/image-import.ts`）：

```bash
# 只识别、预览行列数字（默认不写盘）
npm run import-image -- month.png

# 校验后写入 data/library.json
npm run import-image -- month.png --name "图片导入 · 十二阶" --append

# 更严格的唯一解校验；人工修正：r3=62 改第 3 行，c5=39 改第 5 列（1 基）
npm run import-image -- month.png --verify --map r3=62,c5=39 --append
```

| 参数 | 说明 |
|------|------|
| `--name 名称` / `--id ID` | 题库名称 / 指定 id（覆盖同 id 条目） |
| `--append` | 写入 `data/library.json`；不加只预览 |
| `--verify` | 唯一解校验（小盘面回溯；`--allow-multi` 可放宽） |
| `--map 修正` | `r3=62` 改行目标、`c5=39` 改列目标 |
| `--max-nodes N` | 回溯搜索节点上限 |
| `--out FILE` / `--json` | 题库文件 / 机器可读输出 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **导入题目**：文本粘贴题面编码，或从截图识别行列数字（上限 20×20），校验后入库
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：每次落子一步，拖拽涂写逐格回退
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 项目结构

```
src/
  main.ts
  core/
    app.ts / ui.ts / view.ts      界面、交互、缩放、回放控制
    store.ts / library.ts         题库、进度、上次题目存储
    audio.ts / fx.ts              音效与落子特效
  game/
    adapter.ts                    游戏规则接入
    rules.ts                      推理规则
    logic.ts                      逻辑解题回放
    render.ts / state.ts          SVG 渲染与盘面状态
    validate.ts / solver.ts       实时校验与回溯求解
    puzzles.ts / puzzles-data.ts  题库加载与静态题库
    image-import.ts               图片识别（网格定位 + 数字字形匹配）
    image-import-panel.ts         图片导入面板
    text-import.ts                题面文本解析
    text-import-panel.ts          文本导入面板
```

## 命令

```bash
npm run dev       # 开发服务
npm start         # 开发服务 + 自动打开浏览器
npm run build     # tsc --noEmit + vite build
npm run gen       # 重新生成题库
npm run check     # 审计题库
npm run verify    # 参考解、逻辑回放与交互验证
npm run import-image  # 图片识别导入（预览 / --append / --verify / --map）
npm run audit     # 逐题审计逻辑解题
```

## 尺寸与棋盘支持

| 项目 | 范围 / 说明 |
|------|------|
| 棋盘形状 | 矩形，宽高各自独立 —— 行权重 1..w、列权重 1..h，**支持非正方形**（例如 12×20，已用脚本验证规则引擎 / 求解器 / 编解码） |
| 异形棋盘 | 不支持（每个格子都要么涂黑、要么留白，没有盘外格） |
| 内置题 | 6×6、7×7、8×8 |
| 自定义题板 | 5×5 – 20×20（本批从 15×15 提升），宽高分别设置，只在下方录入行 / 列目标和 |
| 导入 | 文本导入 + 图片导入 ≤ **20×20**（本批从 15×15 提升）；回溯确认有解 ≤12 阶，更大的盘面只做规则引擎校验 |
| 上限 | 行目标 0..w(w+1)/2、列目标 0..h(h+1)/2；超过 144 格的自定义题跳过唯一解校验 |
| 旧数据兼容 | 题面（行目标|列目标）与进度存档格式未变，旧题库完全兼容 |
